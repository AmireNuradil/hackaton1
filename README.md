# Afterimage

**ArtTech · Make the Invisible Visible**

Afterimage превращает день из личного дневника в короткую кинематографическую сцену. Автор добавляет текст, фотографии и музыку, смотрит сцену и возвращается к ней через архив.

## Запуск

Нужен Node.js 20.19+ и современный браузер.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Шесть примеров доступны сразу. Чтобы записать свой день, нажмите **New memory**, добавьте текст, 1–6 фотографий и аудиофайл либо HTTPS-ссылку на песню. Для ссылки укажите темп и энергию на слух. **Create memory** сохранит день и откроет просмотр. **Archive → My memories** показывает ваши записи. **Download day** сохраняет отдельную ZIP-папку дня.

```bash
npm test
npm run build
npm run preview
```

Сборку `dist/` можно размещать на статическом хостинге в любой подпапке. Собранный прототип можно запустить без установки зависимостей: распакуйте архив, выполните `python3 -m http.server 8000` в папке сборки и откройте `http://localhost:8000`. Приложение работает без API и CDN. Открытие ссылки на песню требует доступа к музыкальному сервису.

## Как получается сцена

- **Текст**. Короткое название берётся из фразы записи. Слова и детали на русском или английском меняют характер движения, а подпись сохраняет фразу автора.
- **Фото**. Canvas оценивает цвет и освещённость фотографий. Цвет смешивается с палитрой сцены, а кадры сменяются во время просмотра.
- **Музыка**. Web Audio извлекает из файла примерный темп и энергию. Они меняют длительность кадра, скорость перехода, движение и насыщенность. Ссылки используют описанные пользователем характеристики. При ритмически неоднозначном аудио указывается, что устойчивый ритм не найден.

В **How this memory was made** можно сверить исходный сигнал и его вклад. В папке дня находятся исходный текст, фотографии, трек или ссылка, `day.json` с параметрами и `memory.html` для автономного просмотра. Личные данные сохраняются в IndexedDB этого браузера. Для переноса или резервной копии скачайте папку дня. Очистка данных сайта удаляет локальные записи.
