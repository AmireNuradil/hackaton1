# Тон дня

**ArtTech · Make the Invisible Visible**

Личный дневник, который сохраняет не то, как выглядел день, а то, как он ощущался. Человек пишет о дне, прикладывает 1–6 фотографий и песню. Дневник читает настроение текста, берёт цвета снимков и измеряет темп, энергию и лад музыки. По правилам единой визуальной системы он собирает живую страницу 4:5: подходящий художественный приём, палитра, ритм кадров, подпись от руки и озвучка. День получает короткое название и ложится в свою папку.

[Описание на одну страницу и художественные приёмы](SUBMISSION.md) · [Примеры шести дней](examples/README.md) · [Сценарий демо](DEMO.md)

## Запуск

Нужны Node.js 20.19+ (или 22.12+) и Chromium, Chrome, Edge, Firefox или Safari последних версий.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Шесть примеров собираются при загрузке тем же кодом, что и ваши дни. **Записать день** → текст, фото, песня (файл или ссылка с описанием) → **Собрать страницу дня**. В просмотре: **Смотреть** проигрывает страницу с песней, **Озвучка** читает запись голосом, подобранным по правилам, **Сохранить папку дня** записывает папку (в Chromium — настоящую папку на диске, в других браузерах — ZIP).

Статическая сборка работает из любой подпапки и без интернета: шрифты, примеры и библиотеки входят в неё.

```bash
npm test          # 20 модульных тестов: текст, музыка, правила, папка дня
npm run build     # сборка в dist/
npm run preview   # http://localhost:4173
```

### Проверка в браузере

При запущенном `npm run preview` и установленном Playwright (`npm i -g playwright`):

```bash
node scripts/check-browser.mjs
```

Скрипт загружает примеры и создаёт день с аудиофайлом и день со ссылкой. Он проигрывает страницу и сохраняет папку дня с видео, открывает из неё `memory.html`, перезагружает архив и проверяет телефонную ширину. `node scripts/export-examples.mjs` заново рендерит изображения в `examples/`.

## Что лежит в папке дня

| Файл | Содержимое |
|---|---|
| `entry.txt` | Запись дня как есть |
| `photo-01.jpg` … | Исходные фотографии |
| `song.mp3` или `song-link.txt` | Песня-файл или ссылка на музыкальный сервис |
| `memory.webm` | Готовое воспоминание: видео страницы с песней |
| `poster.png` | Кадр страницы для ленты |
| `voice.txt` | Текст и параметры озвучки |
| `memory.html` | Автономный просмотр: видео, запись, «Слушать запись», объяснение |
| `day.json` | Анализ входных данных, параметры страницы и причины каждого решения |

## Устройство

| Файл | Роль |
|---|---|
| `src/text.js` | Лексикон RU/EN: окраска, подвижность, ностальгия; время суток, сезон, место, люди; название в 3–7 слов |
| `src/photo.js` | k-means-палитра, свет, контраст, теплота снимков |
| `src/music.js` | FFT, темп по автокорреляции онсетов, энергия, мажор/минор по профилям Крумхансла |
| `src/system.js` | Правила визуальной системы и объяснения |
| `src/render.js` | Отрисовка страницы на Canvas: постоянная рамка и пять приёмов |
| `src/video.js`, `src/folder.js` | Видео через MediaRecorder и папка дня |
| `src/main.js`, `index.html`, `src/style.css` | Интерфейс, IndexedDB-архив, озвучка Web Speech |

Дни хранятся в IndexedDB браузера. Ничего не уходит на сервер, и API не используются.
